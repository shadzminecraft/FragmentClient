# FragmentClient
In-Work Minecraft Mod That Makes your Game Look like a Minecraft Client(Lunar Client). Powers with Mod OneConfig

FragmentClient

An independent Minecraft client project built around customization, functionality, and an improved Minecraft experience.

About

FragmentClient is a project aiming to bring customizable client features and a modern interface to Minecraft.

Goals

- Customizable HUD
- Modern user interface
- Minecraft Fabric compatibility
- Performance and usability improvements
- Community-driven development

Development Status

Currently in development. More features and improvements are planned.

Developer

Independent developer passionate about Minecraft, software development, and gaming communities.
